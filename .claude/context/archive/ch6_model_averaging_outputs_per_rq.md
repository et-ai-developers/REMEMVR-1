### Standard Output Set (step05b_*.csv)

Each ROOT RQ that underwent model averaging produces this standard set of 5 files:

#### 1. step05b_competitive_models.csv

**Purpose:** Documents all models with ΔAIC < 7 and their renormalized weights

**Columns:**
- `model_name`: Model identifier (e.g., 'PowerLaw_10', 'Sin+Cos')
- `aic`: Original AIC value from kitchen sink comparison
- `delta_aic`: AIC difference from best model
- `akaike_weight`: Original weight (may sum to <1 if some models excluded)
- `renormalized_weight`: Weight renormalized to sum to 1.0 across competitive set
- `converged`: Boolean (TRUE/FALSE)

**Usage:**
- Identify which models contribute to final predictions
- Verify renormalized weights sum to 1.0
- Check distribution of evidence (concentrated vs dispersed)

**Example (RQ 6.8.1):**
- 51 rows (out of 66 total models)
- Renormalized weights range: 0.007 to 0.042
- All converged=TRUE (non-converged excluded automatically)

#### 2. step05b_model_averaged_predictions.csv

**Purpose:** Model-averaged fitted values with unconditional variance

**Columns:**
- `UID`: Participant identifier
- `Test`: Test session (T1, T2, T3, T4)
- `Days`: Days since encoding
- `ma_prediction`: Weighted average of predictions across competitive models
- `unconditional_variance`: Total variance including model selection uncertainty (B&A 2002 eq 4.9)
- `unconditional_se`: Square root of unconditional_variance
- Additional factor columns (e.g., `LocationType` for 6.8.1, `domain` for 6.3.1)

**Formula for unconditional_variance:**
```
V_unc = Σ w_i * [V_i + (μ_i - μ_MA)²]
where:
  w_i = renormalized Akaike weight for model i
  V_i = conditional variance from model i
  μ_i = prediction from model i
  μ_MA = model-averaged prediction
```

**Usage:**
- Replace single-best predictions in plots
- Use unconditional_se for confidence intervals
- Compare to conditional SE to quantify model uncertainty

**Example (RQ 6.8.1):**
- 800 rows (100 UIDs × 4 Tests × 2 LocationTypes)
- ma_prediction range: -1.2 to 0.8 (theta scale)
- unconditional_se typically 0.05-0.15 (larger than conditional)

#### 3. step05b_model_averaged_theta.csv

**Purpose:** Model-averaged theta values for derivatives that need theta inputs

**Columns:**
- `UID`: Participant identifier
- `Test`: Test session
- `ma_theta`: Model-averaged theta estimate
- Factor columns as applicable

**Usage:**
- Input to derivative RQs (e.g., 6.1.4 ICC decomposition uses 6.1.1 theta)
- Sensitivity analysis: Compare derivative results using single-best vs MA theta

**Example (RQ 6.1.1):**
- 400 rows (100 UIDs × 4 Tests)
- ma_theta range: -1.5 to 0.5
- Used as input to RQ 6.1.4 (ICC decomposition)

#### 4. step05b_model_averaged_random_effects.csv

**Purpose:** Model-averaged random intercepts and slopes

**Columns:**
- `UID`: Participant identifier
- `ma_intercept`: Weighted average of random intercepts across models
- `ma_slope`: Weighted average of random slopes (if models include random slopes)
- Additional columns for multi-factor models

**Critical for:**
- ICC calculations (variance of ma_intercept)
- Individual difference analyses
- Clustering analyses (6.8.4 uses these as features)

**Formula:**
```
ma_intercept[UID=i] = Σ w_j * intercept[UID=i, model=j]
where j iterates over competitive models
```

**Example (RQ 6.1.1):**
- 100 rows (one per participant)
- ma_intercept SD = 0.314
- ma_slope SD = 0.099
- **Impact:** 824× ICC ratio now based on model-averaged variance components

**Example (RQ 6.8.1):**
- 100 rows
- ma_intercept only (no random slopes in 6.8.1)
- Used for Source-Destination ICC derivative

#### 5. step05b_metadata.csv

**Purpose:** Summary statistics about model averaging process

**Columns:**
- `effective_n`: Effective number of models (1/Σw²)
- `n_competitive_models`: Count of models with ΔAIC < 7
- `total_weight_captured`: Sum of renormalized weights (should be 1.0)
- `best_model_weight`: Weight of single best model
- `delta_aic_threshold`: Threshold used (7.0)

**Usage:**
- Document level of model uncertainty
- Justify need for model averaging
- Report in thesis methods section

**Example outputs:**

| RQ | effective_n | n_competitive | best_weight |
|----|-------------|---------------|-------------|
| 6.8.1 | 43.4 | 51 | 0.042 |
| 6.1.1 | 31.1 | 48 | 0.217 |
| 6.3.1 | 2.4 | 4 | 0.556 |
| 6.4.1 | 2.0 | 2 | 0.500 |
| 6.5.1 | 1.8 | 2 | 0.653 |

### Usage in Derivative RQs

**Derivative RQs have NOT been re-run with MA outputs.**

**Current state:**
- Derivatives use single-best outputs from ROOT RQs
- MA outputs exist in ROOT RQ data/ folders
- Available for future sensitivity analyses

**How to use MA outputs in derivatives:**

1. **RQ 6.1.4 (ICC decomposition from 6.1.1):**
   - Currently uses: `step03_theta_confidence.csv` (single-best theta)
   - Could use: `step05b_model_averaged_theta.csv` (MA theta)
   - Expected impact: Minor (ICC ratios likely robust)

2. **RQ 6.8.2-6.8.4 (Source-Dest derivatives from 6.8.1):**
   - Currently use: Single-best theta/random effects
   - Could use: `step05b_model_averaged_theta.csv` and `step05b_model_averaged_random_effects.csv`
   - Expected impact: Minimal (NULL findings likely robust)

**Recommendation for thesis:**
- Report that MA was implemented for ROOT RQs
- Note that derivatives use single-best (conservative approach)
- Acknowledge as limitation if reviewer questions
- Sensitivity analysis available if needed
