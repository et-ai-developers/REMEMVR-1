### Strategic Rationale

**Why NOT Sequential Ch5 Certification:**

1. **Time constraint:** ~50 Ch5 RQs × 1h each = 50h (too long for diminishing returns)
2. **Redundancy risk:** Many Ch5 RQs test similar patterns already validated in Ch6
3. **Narrative efficiency:** Ch6 provides cleaner baseline/trajectory framework
4. **Thesis timeline:** Strategic selection more impactful than exhaustive coverage

**Why Targeted Approach:**

1. **High-impact discoveries:** Focus on RQs with unique theoretical contributions
2. **Cross-chapter validation:** Strengthen Ch6 findings via Ch5 convergence
3. **Methodological innovation:** Prioritize RQs demonstrating new analysis techniques
4. **Narrative integration:** Select RQs that enhance thesis coherence

---

### Selection Criteria

**Tier 1 - MUST CERTIFY (High Priority):**

1. **Cross-Chapter Validation:**
   - Ch5 RQs that replicate/extend Ch6 baseline framework
   - Accuracy equivalents of Ch6 confidence patterns
   - Examples: Age-invariant forgetting, domain dissociation, schema encoding effects

2. **Unique Theoretical Contributions:**
   - Patterns found ONLY in accuracy (not in confidence)
   - Novel discoveries with thesis-level narrative impact
   - Examples: VR scaffolding effects, exceptional learner phenotypes

3. **Methodological Innovations:**
   - First applications of advanced techniques (GEE, extended LMM suites, clustering)
   - Demonstrations of power law vs logarithmic model selection
   - Examples: RQ 5.1.1 (17-model comparison), binary outcome GEEs

**Tier 2 - CONDITIONAL (Medium Priority):**

1. **Moderate Theoretical Interest:**
   - Patterns with some narrative value but not thesis-defining
   - Incremental contributions to established frameworks

2. **Partial Redundancy with Ch6:**
   - Tests similar hypotheses but on accuracy instead of confidence
   - Value = convergent evidence (not new discovery)

**Tier 3 - DEFER/SKIP (Low Priority):**

1. **High Redundancy:**
   - Exact replications of Ch6 patterns with no new insights
   - Already-validated null findings with no theoretical controversy

2. **Low Narrative Integration:**
   - Standalone analyses with minimal connection to main thesis themes
   - Exploratory work that didn't yield significant patterns

### Implementation Strategy

**Phase 1: Inventory (CURRENT)**
- List all Ch5 RQs with current certification status
- Classify into Tier 1/2/3 using selection criteria
- Identify ~10-15 Tier 1 RQs for targeted certification

**Phase 2: Targeted Certification**
- Run rq_platinum on Tier 1 RQs sequentially

- Cross-reference with Ch6 convergent findings
- Estimated time: 10-15h (vs 50h exhaustive)

**Phase 3: Narrative Integration**
- Update thesis chapter introductions with cross-chapter themes
- Create convergence tables (accuracy vs confidence patterns)
- Document theoretical implications of divergences
- Highlight methodological innovations

**Phase 4: Thesis Defense Preparation**
- Identify "showcase RQs" for defense presentation
- Prepare cross-chapter comparison slides
- Document theoretical framework synthesis
