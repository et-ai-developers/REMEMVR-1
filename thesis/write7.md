## WHY THIS CHAPTER MATTERS (Narrative Arc)

**Ch7's Role in the Thesis:**
Ch5 established **WHAT HAPPENS** (forgetting patterns). Ch6 asked **Does confidence TRACK it?** (metacognition). Ch7 asks: **What PREDICTS individual differences?**

**The Central Thesis Question:**
"How well do standard neuropsychological tests predict real-world episodic memory performance as measured by REMEMVR?"

**The Story Ch7 Will Tell (When Executed):**
1. **External validity:** Do RAVLT/BVMT/RPM predict REMEMVR performance?
2. **Domain specificity:** RAVLT (verbal) → What? BVMT (visuospatial) → Where? Neither → When?
3. **Intercept vs slope:** Do tests predict encoding ability (baseline) or forgetting rate (slope)?
4. **Age dissociation:** Traditional tests show robust age effects (contrasting Ch5 §5.3 VR age-invariance)
5. **Unique variance:** REMEMVR taps ecological episodic memory beyond what pen-and-paper tests capture

**Why This is Exciting (When We Have Data):**
- VR age-invariance (Ch5 §5.3) vs traditional test age-sensitivity (Ch7) reveals paradigm-specific scaffolding
- RAVLT-VR correlation tests whether word-list memory predicts real-world episodic memory
- Unique variance quantifies what VR adds beyond standard clinical assessment
