### §6.3 High-Confidence Errors: Monitoring Failure, Not False Memory (~2,500 words)

**Narrative Arc:** "15-20% of errors made with high confidence. Why? Metacognitive monitoring failure, not memory reconstruction."

**Why This Theme Matters:**
If HCE rate INCREASES over time → false memory reconstruction (traces fade, people fill gaps with plausible errors).
If HCE rate STABLE over time → monitoring failure (people can't tell correct from incorrect, not generating false memories).

**Key Finding:** HCE rate STABLE across delays (no temporal increase). Driven by metacognition, not memory.

#### Flagship RQs (2-3):
1. **RQ 6.6.1 - General HCE Patterns** (~900 words)
   - 15-20% of errors made with Confidence≥4 (high-confidence errors)
   - HCE rate stable Day 0→6 (no increase over time)
   - Interpretation: NOT false memory generation, but monitoring inability
   - Contrast with reconstruction hypothesis (would predict increasing HCE rate)

   - Content-specific HCE rates

3. **RQ 6.6.2 - Dunning-Kruger Effect** (~600 words)

   - Low performers do NOT show overconfidence bias
   - Challenges popular metacognitive theory

### §6.4 Confidence-Accuracy Dissociation (~2,000 words)

**Narrative Arc:** "Where do confidence and accuracy diverge? Measurement sensitivity and spatial memory architecture."

**Why This Theme Matters:**
Perfect correspondence → single underlying construct. Dissociation → dual-systems (memory architecture vs metacognitive monitoring partially independent).

**Key Finding:** OPPOSITE correlations for spatial memory (source-dest accuracy +0.99/-0.90 vs confidence -0.24/-0.40).

#### Flagship RQs (2):
