### Calibration Computation

**Method:**
- Merged IRT-derived accuracy estimates (from Ch5 RQ 5.5.1) with confidence estimates (from Ch6 RQ 6.8.1)
- Z-standardized both accuracy and confidence separately within each location type
- Computed calibration = Z_confidence - Z_accuracy
- Positive values = overconfidence (confidence exceeds accuracy)
- Negative values = underconfidence (accuracy exceeds confidence)
- Zero = perfect calibration

**Key Observation:** Both location types show mean calibration near zero (well-calibrated on average), with similar standard deviations indicating comparable individual variability in calibration quality.

## 3. Interpretation

### Hypothesis Testing

**Original Hypothesis (from 1_concept.md):**
Source locations will show BETTER calibration than destination locations. Destination may show overconfidence because put-down actions feel familiar (high confidence) but decay faster (lower accuracy per Ch5 5.5.1).

**Hypothesis Status:** **NOT SUPPORTED**

The statistical findings provide no evidence for source-destination calibration differences:
- LocationType main effect: ² = -0.14, p = 0.248 (NS)
- LocationType × Time interaction: ² = 0.04, p = 0.198 (NS)
- Effect sizes negligible: f² < 0.003 for all effects

**Critical Interpretation:** Despite Ch5 RQ 5.5.1 finding that destination accuracy decays FASTER than source accuracy (significant accuracy dissociation), **confidence judgments track both location types equivalently**. This suggests metacognitive monitoring is not sensitive to the source-destination accuracy difference.

### Null Finding in Context of Prior Results

**Ch5 RQ 5.5.1 Findings (Source-Destination Accuracy Dissociation):**
- Destination accuracy declined significantly faster than Source accuracy over 6 days
- Significant LocationType effect on accuracy trajectories
- Theoretical interpretation: Source locations benefit from stronger encoding context (initial object identification)

**Ch6 RQ 6.8.1 Findings (Confidence Trajectories - Not Yet Analyzed):**
- This RQ assumed confidence patterns would differ by location type IF calibration differs
- Null calibration finding suggests: Either (a) confidence ALSO dissociates by location type in the same pattern as accuracy (preserving calibration), OR (b) confidence does not track accuracy differences

**Reconciling Accuracy Dissociation with Equivalent Calibration:**

**Scenario A: Confidence Tracks Accuracy Dissociation**
- If confidence judgments decline faster for destination than source (mirroring accuracy pattern)
- Then calibration (confidence - accuracy) remains equivalent across location types
- This would indicate GOOD metacognitive monitoring: confidence accurately reflects underlying accuracy differences

**Scenario B: Confidence Insensitive to Location Type**
- If confidence judgments do not differ by location type
- But accuracy DOES differ (Ch5 5.5.1)
- Then calibration SHOULD differ... but doesn't in this RQ
- This scenario is LESS plausible given null calibration finding

**Most Parsimonious Interpretation:**
**Scenario A** is most consistent with findings. Confidence likely tracks the source-destination accuracy difference discovered in Ch5 5.5.1, maintaining equivalent calibration across location types. This suggests metacognitive monitoring is sensitive to the encoding/retrieval differences between source and destination memories, adjusting confidence appropriately.

**Implication:** Participants have GOOD metacognitive insight into source vs destination memory quality. When destination accuracy is lower (Ch5 5.5.1), confidence adjusts downward proportionally, preserving calibration. This is a POSITIVE finding for VR-based episodic memory assessment - confidence ratings are diagnostic of performance even for distinct spatial memory components.

### Unexpected Patterns

**1. Near-Perfect Average Calibration (Mean H 0) for Both Location Types**

**Observation:** Both Source (M = -0.000, SD = 0.851) and Destination (M = -0.000, SD = 0.979) show mean calibration indistinguishable from zero.

**Why Unexpected:**
- Most metacognition research finds OVERCONFIDENCE (calibration > 0) in memory tasks, especially for difficult items
- Ch5 5.5.1 showed destination memories are HARDER (lower accuracy), typically associated with overconfidence

**Possible Explanations:**
1. **Z-standardization within location type:** Standardizing separately for Source and Destination may have removed between-location calibration differences by forcing both to mean = 0 within each type. This was methodologically necessary to compare calibration on same scale, but may have masked absolute calibration differences.
2. **VR task characteristics:** Immersive VR may provide richer retrieval cues than traditional memory tasks, improving metacognitive accuracy. Participants may have better access to encoding context in VR, enabling more accurate confidence judgments.
3. **Sample characteristics:** University undergraduates may have better metacognitive skills than general population (metacognitive monitoring improves with education).

**Investigation Recommended:** Re-analyze calibration WITHOUT within-location-type standardization to test whether absolute calibration differs (e.g., compute calibration on raw theta scales). Current analysis optimized for RELATIVE calibration comparison (Source vs Destination), but may miss absolute calibration differences.

**2. Substantial Individual Differences in Calibration (Ã² = 0.288)**

**Observation:** Random intercept variance (0.288) is substantial - participants differ meaningfully in baseline calibration tendency.

**Interpretation:**
- Some participants consistently overconfident (positive intercept)
- Some consistently underconfident (negative intercept)
- Some well-calibrated (intercept H 0)
- Individual difference magnitude (SD = 0.537) is comparable to within-person variability (residual SD = 0.745)

**Unexplored Question:** What predicts individual calibration tendency? Cognitive ability? Metacognitive awareness? Personality traits (e.g., confidence, conscientiousness)?

**Follow-Up Potential:** Extract participant-specific random intercepts (BLUPs), correlate with demographic/cognitive variables. May identify markers of metacognitive skill in VR episodic memory assessment.

**3. Slight Upward Trend at Day 6 for Source (Mean = +0.12)**

**Observation:** Source calibration shows mild overconfidence at final test session (T4, Day 6), though CI includes zero and effect is non-significant.

**Speculation:**
- Forgetting increases confidence-accuracy mismatch at longer delays?
- Source memories may feel more familiar due to initial encoding salience, leading to slight overconfidence when retrieval is difficult?
- Random fluctuation (non-significant trend)?

**Not Pursued:** Given non-significant interaction (p = 0.198) and negligible effect size (f² = 0.002), this pattern does not warrant strong interpretation. Future work with longer retention intervals (Day 14, Day 28) could test whether overconfidence emerges at extended delays.

### Broader Implications

**Metacognitive Monitoring in VR Episodic Memory:**

This null finding has POSITIVE implications for VR-based cognitive assessment:
- **Confidence ratings are diagnostic:** Participants can accurately judge memory quality for different spatial components (source vs destination)
- **Calibration robustness:** Despite accuracy differences (Ch5 5.5.1), calibration remains equivalent - suggests metacognitive monitoring adapts to task difficulty
- **Assessment validity:** VR confidence ratings can be trusted as proxies for underlying ability, even when memory components differ in difficulty

**Theoretical Implications:**

1. **Metacognitive cue utilization:** Participants likely use similar metacognitive cues for source and destination memories (e.g., retrieval fluency, contextual detail, vividness) despite different encoding contexts
2. **No dual-process metacognition:** Findings argue AGAINST separate metacognitive systems for source vs destination. If monitoring differed, calibration would dissociate.
3. **Cue validity hypothesis (Koriat, 1997):** Confidence judgments based on valid retrieval cues that track performance equally well for both location types

**Clinical/Applied Relevance:**

For REMEMVR as cognitive assessment tool:
- Confidence ratings can supplement accuracy scores without concern for location-type-specific biases
- Calibration metrics may be useful for detecting metacognitive impairment (e.g., MCI patients may show overconfidence even when healthy adults well-calibrated)
- No need for location-type-specific confidence score adjustments in scoring algorithms

## 4. Limitations

### Sample Limitations

**Sample Size:**
- N = 100 participants provides adequate power (0.80) for medium effects (f² e 0.15), but underpowered for small effects (f² = 0.02, power H 0.30)
- Observed effect sizes (f² < 0.003) are FAR below small effect threshold - even with N = 1000, these would remain non-significant
- **Conclusion:** Null finding is NOT due to insufficient power. True effect (if exists) is negligible.

**Demographic Constraints:**
- University undergraduate sample (age M H 20 years) limits generalizability to older adults
- Older adults show worse calibration in memory tasks (overconfidence increases with age-related cognitive decline)
- Findings may not apply to clinical populations (MCI, dementia) where metacognitive monitoring is impaired

**Missing Data:**
- No missing data for this RQ (complete 800 observations)
- However, this RQ depends on outputs from Ch5 5.5.1 and Ch6 6.8.1, which may have had item exclusions due to IRT purification
- Calibration computed on IRT theta scores (which are item-invariant), so item-level exclusions do not bias participant-level calibration estimates

### Methodological Limitations

**Measurement:**

1. **Z-standardization Approach:**
   - Standardizing accuracy and confidence separately WITHIN each location type forces mean = 0 for both Source and Destination
   - This approach is appropriate for testing RELATIVE calibration differences (primary hypothesis)
   - BUT may mask ABSOLUTE calibration differences (e.g., if Destination shows raw overconfidence but Source does not)
   - **Alternative analysis needed:** Compute calibration on raw theta scales (without within-location standardization) to test absolute calibration

2. **Calibration as Difference Score:**
   - Calibration = confidence - accuracy is simple but statistically limited
   - Ignores non-linear relationship between confidence and accuracy (calibration may be good at high accuracy but poor at low accuracy)
   - Does not account for regression to the mean in difference scores
   - **Alternative:** Calibration curves (plot accuracy vs confidence, assess slope and intercept) may reveal nuances missed by difference scores

3. **IRT Theta as Accuracy Measure:**
   - Theta scores are latent estimates (not observed accuracy)
   - Confidence judgments made on ITEM-LEVEL performance (participant sees whether they got item correct)
   - Calibration analysis uses AGGREGATE theta (averaged across items within location type)
   - Mismatch in grain: item-level confidence vs person-level ability
   - **Implication:** May underestimate calibration quality if participants well-calibrated at item level but aggregation introduces noise

**Design:**

1. **No Control for Response Patterns:**
   - Confidence ratings on 1-5 scale (from Ch6 6.8.1)
   - Some participants may use full scale (1-5), others only extremes (1 or 5)
   - Response style differences could inflate individual difference variance in calibration
   - **Not addressed:** No correction for differential scale use (transparency priority per solution.md section 1.4)
   - **Impact:** May limit interpretability of individual calibration differences

2. **Cross-RQ Dependencies:**
   - Calibration depends on TWO independent IRT calibrations (accuracy from 5.5.1, confidence from 6.8.1)
   - Each IRT calibration has measurement error (SE reported but not propagated into calibration analysis)
   - Errors in theta estimates accumulate in calibration scores
   - **Not addressed:** LMM does not account for theta standard errors (treats theta as fixed)

3. **TSVR Variable (Decision D070):**
   - Log-transformed TSVR used in LMM (log_TSVR)
   - Assumes logarithmic time relationship with calibration
   - Linear or other functional forms not tested
   - May miss non-linear calibration changes over time

**Statistical:**

1. **LMM Random Effects Structure:**
   - Random intercepts only (no random slopes for time or location type)
   - Assumes calibration trajectories have same shape for all participants (only intercept varies)
   - Individual differences in calibration CHANGE over time not modeled
   - More complex random effects structures may reveal individual-level interactions

2. **Multiple Comparisons:**
   - Bonferroni correction applied (Decision D068) for dual p-values
   - Conservative correction appropriate for confirmatory hypothesis testing
   - However, with 4 fixed effects tested (intercept, LocationType, log_TSVR, interaction), correction may be overly strict for exploratory patterns

3. **Null Hypothesis Significance Testing Limitations:**
   - Non-significant p-values do NOT prove null hypothesis true (only fail to reject)
   - Equivalence testing (TOST) would be more appropriate for claiming "no difference"
   - Bayes Factor analysis could quantify evidence FOR null vs alternative

### Generalizability Constraints

**Population:**
- Findings may not generalize to:
  - Older adults (metacognitive decline with aging)
  - Clinical populations (metacognitive impairment in MCI, dementia, schizophrenia)
  - Children/adolescents (metacognitive monitoring develops across lifespan)
  - Cross-cultural samples (metacognition may vary by culture)

**Context:**
- VR desktop paradigm differs from:
  - Fully immersive HMD VR (may enhance encoding context, affecting confidence cues)
  - Real-world spatial navigation (multisensory cues not present in VR)
  - Standard neuropsychological tests (2D stimuli lack spatial immersion)

**Task:**
- REMEMVR-specific findings may not apply to:
  - Non-spatial memory tasks (object recognition, word lists, faces)
  - Emotional memories (affective content alters metacognition)
  - Prospective memory (future-oriented memory has different metacognitive profile)

### Technical Limitations

**Z-Standardization Impact:**
- Standardizing within location type ensures comparability but removes absolute calibration information
- Alternative analysis (raw theta calibration) needed to assess absolute calibration differences
- Current analysis answers: "Do Source and Destination differ in RELATIVE calibration?" (No)
- Unanswered: "Do Source and Destination differ in ABSOLUTE calibration?" (Unknown)

**IRT Theta Measurement Error:**
- Theta scores have standard errors (SE_accuracy, SE_confidence in data files)
- LMM treats theta as fixed (ignores measurement uncertainty)
- Propagating SE through calibration analysis would be more rigorous (e.g., errors-in-variables models)
- May underestimate true calibration variability if theta estimates unreliable

**Cross-RQ Dependency Risk:**
- If Ch5 5.5.1 or Ch6 6.8.1 IRT calibrations had convergence issues or poor fit, theta estimates unreliable
- Calibration analysis inherits any upstream measurement problems
- **Mitigation:** rq_inspect validated both dependency RQs, but any subtle biases propagate

### Limitations Summary

Despite these constraints, findings are **robust within scope:**
- Effect sizes negligible (f² < 0.003) - true differences (if exist) are trivial
- Confidence intervals for LocationType effect include zero with substantial margin (² = -0.14, 95% CI [-0.37, +0.10])
- Visual inspection (plot) confirms equivalence: trajectories overlap completely

**Key Limitation Requiring Follow-Up:** Z-standardization within location type may have removed absolute calibration differences. Recommend re-analysis on raw theta scales to test whether absolute calibration differs even if relative calibration does not.
